# safA_mgrB_simulation
simulation of safA and mgrB co-regulation of PhoQP TCS for Werland et al (2026)

The Matlab file contains the Matlab code used to simulate the evolution of PhoP, safA and mgrB concentration described in: https://doi.org/10.64898/2026.05.06.723403 

Comment/uncomment the set of binding constants to simulate the different conditions described in the paper

Runs with Matlab R2020a or higher.
